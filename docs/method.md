# 方法说明与适用边界

本文说明应用如何把合成资料转成“可审批的报价方案”，以及哪些结论不能从资料推出。

## 1. 质量估计

### 检测基础

* 含水率 `moisture_fraction` 是湿基水质量 / 湿总质量。
* 杂质 `impurity_fraction_dry` 与聚合物 `polymer_fraction_dry` 是干基质量分数。
* 干重 = 湿重 × (1 − 含水率)。干基指标不再乘一次干物质比例；湿基吨数也不与干基分数直接相加。
* 同一指标内的分层加权：湿基指标按代表湿重加权，干基指标按代表干重（代表湿重 × 干物质比例）加权。

### 取样代表性

* `random_mass` 视为随机质量取样，用于无偏中心估计。
* `targeted` 不拥有随机代表性。中心估计不使用定向层；定向层只用于：审核偏坏、`adverse` 压力情景。
* 覆盖 = 随机检测代表湿重合计 / 可见湿重，上限 100%。覆盖不足时，未覆盖部分的差异由同批层内方差或同材质批间方差建模，并加大均值标准误。
* 低于 `coverage_unquotable`（默认 35%）或没有随机检测的料批不可报价；介于该阈值与 `coverage_restricted`（默认 60%）之间的料批只能保留受限方案。
* 代表范围合计超过可见湿重的 105% 会被标记为“覆盖声明可能重复计算”，并按上限截断，不把重复声明当成新增吨数。

### 复测与替代

`supersedes` 只有同时满足以下条件才成立：

1. 同一料批；
2. 同取样层；
3. 同取样基础；
4. 代表范围不小于旧检测；
5. 获知时间不早于旧检测。

任一条件不满足时，两条证据都保留，料批降为 `restricted`，并记录具体冲突。链式替代沿相容关系传递；冲突关系不传递。这样“新日期”不会自动覆盖不相容的旧范围。

### 指标相关性与保守性

资料只有约 12 个塑料批的批均值，无法稳定估计含水、杂质、聚合物三者的相关结构。应用因此：

* 中心计划用各指标中心估计；
* 风险模拟默认使用“不利共变”相关矩阵（杂质高与聚合物低共同出现），并提供 `independent` 对照；
* 情景对比表（`central` / `adverse` / `pooled`）只用于说明差异，不把各指标最有利的界拼成一个不存在的“好料”。

## 2. 产出率与成本

* 拟合对象：可售干重 / 投入干重；解释变量：配方指示、含水率、杂质。
* 只使用 `fold = development` 的试验；`holdout` 只做回测。
* 交叉验证按 `trial_lot` 分组。同 trial_lot 的平行试验不是独立样板，不能按记录条数计样本量。
* 配方只代表批准的工艺类别。资料中配方间中心差异小于残差标准差；报告会明确“数据无法区分”，不预设某个配方胜出。
* 加工变动成本按试验记录的“加工费 / 投入湿重”估计；班次固定成本来自 capacity。
* 产出率随机项 = 残差分布 ×（共同因子占比 + 独立项）。资料没有重复的同料批/同配方记录，无法识别共享程度，因此默认 0.5，并在敏感性分析中给出 0 与 1。

## 3. 联合计划

模型是一个混合整数规划，所有承购共享料批与加工日：

* 料批按可用湿重约束（已加工量先扣除），同一批料可在不同订单/日期拆分，但总承诺不超过可用量。
* 加工日按湿基能力共享；启用一个班次付固定成本。
* 每单按整车数量交付；需求不是整车整数倍时按合同整车量计划并在报告中注明。
* 短交变量允许存在，其单位代价 = 单价 + 按合同量分摊的拒收损失。高违约代价的订单会自然获得优先级，不需要按客户分别计算再相加。
* 质量按“可售干重加权”的订单混合均值约束，可加质量裕量。
* `enforce` 的承购短交固定为 0；用于检验“若必须接受这单”的可行性，而不是偷偷把缺交转移给其他单。
* 质量不可满足时返回 `feasible=False` 和原因，不强行给一个等级。

## 4. 风险模拟

* 每个情景一次性抽取整条供应链的随机因素；所有承购共享同一组抽样。质量按料批共享，产出按料批+配方共享。
* 客户复检：在真实混合质量上叠加测量误差，按整车判断；`quality_gate_any_truck` 控制“订单层面任一整车不合格”还是“单车不合格”。
* 收入按实际交付（扣除缺交与拒收整车）计；拒收同时损失该批收入并支付按比例分摊的拒收损失。
* 校准：先用较小质量裕量找可行区间，再逐步上调直到质量风险下降；产出缓冲按缺交风险逐步增大，接近边界时缩小步长。若任何正裕量或缓冲都不可行，报告保留上一轮并说明原因，而不是伪称达标。
* 预测区间描述模型条件下的条件分布，不是对每车质量的保证，也不替代合同条款。

## 5. 报价、接受与后续

* 报价快照记录：使用的料批与检测身份、覆盖、当时的质量中心估计、质量情景、假设、价格有效期。
* 快照写入后不可覆盖；接受、取消、新检测、加工回执、客户复检处置都追加为独立决策。
* 已加工数量是沉没投入：从可用湿重扣除，取消不会把它退还原批次。
* 未加工的承诺在取消后才释放。
* 客户复检处置：
  * `accept`：按实际等级确认收入；
  * `recheck`：等待重检，暂不确认该部分收入；
  * `dispute`：争议中，暂不确认收入且不回库存；
  * `return`：退货，不确认收入，也不回原批次。
* 复检结论只改变剩余履约与已实现利润；当时报价用了哪些证据保持不变。
* 重判会检查：证据均值变化、覆盖变化、证据状态变化、料批可用量不足、加工日不可用、价格过期、推荐组合变化、同组合期望毛利变化。任一触发即要求重新审批。

## 6. 明确不计入

* 原料取得成本（资料没有采购价）。
* 未列明的运输、仓储、资金成本、税费。
* 客户复检的系统偏差（只有一个争议案例，不能标定）。
* 检测抽样本身的系统偏差。
* 真实合同条款、罚则细节与法律解释。

## 7. 资料限制

* 合成资料，不代表真实居民、企业、金额或政策。
* `actuals` 只有 2 条，且 `processed` 不等于客户已接受合格货。
* 试验 `known_at` 全部早于决策日，因此试验可用于拟合；检测有明确获知时间，决策日之后的检测不会进入当时报价。
